Actúa como un arquitecto de software senior especializado en backend con ASP.NET Core (.NET 8), diseño limpio y sistemas de producto reales.

Estoy construyendo una plataforma técnica personal con:

- Frontend: Next.js (App Router, TypeScript, arquitectura basada en features/)
- Backend: ASP.NET Core Web API (.NET 8)
- Base de datos: PostgreSQL con Entity Framework Core

El backend debe ser diseñado como un sistema profesional, no como un CRUD simple.

---

OBJETIVO

Construir un backend robusto, seguro y mantenible que permita:

- Gestionar proyectos (portafolio)
- Gestionar artículos técnicos (blog)
- Gestionar tags reutilizables
- Exponer endpoints públicos para consumo del frontend
- Proteger endpoints administrativos mediante autenticación

---

REQUISITOS DE ARQUITECTURA

Diseña el sistema bajo principios de Clean Architecture pragmática:

Capas:

- Domain (entidades puras)
- Infrastructure (EF Core, DbContext, persistencia)
- Application (lógica de negocio ligera si aplica)
- API (Controllers, DTOs, autenticación)

Evita sobreingeniería:
- No usar CQRS complejo
- No usar MediatR innecesariamente
- Mantener claridad y simplicidad

---

SEGURIDAD (CRÍTICO)

Implementa autenticación basada en JWT:

- Endpoint de login: /api/auth/login
- Uso de JWT Bearer tokens
- Hash seguro de contraseña (bcrypt o equivalente)

Diseña el sistema como una plataforma personal, por lo tanto:

- No se requiere registro público
- Debe existir un usuario administrador único

Implementa:

1. Seed inicial de usuario admin:
   - Email
   - Password hasheado
   - Rol: Admin

2. Middleware de autenticación

3. Protección de endpoints:

- Públicos:
  - GET /api/projects
  - GET /api/projects/{slug}
  - GET /api/blog
  - GET /api/blog/{slug}

- Protegidos:
  - /api/admin/*
