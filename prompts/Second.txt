# 🎨 SISTEMA DE DISEÑO (CRÍTICO)

Debes implementar un sistema visual consistente.

### Layout

- usar max-width (NO full stretch)
- contenido centrado
- padding consistente
- grid limpio

Ejemplo conceptual:
→ max-w-5xl o max-w-6xl
→ spacing vertical amplio

---

### Jerarquía visual obligatoria

Cada página debe tener:

1. Título principal (claro)
2. Subtítulo explicativo
3. Secciones separadas
4. Espaciado entre bloques

---

### Espaciado (MUY IMPORTANTE)

- separación entre secciones (mínimo 32px)
- padding interno en cards
- evitar bloques pegados

---

### Cards (NO listas planas)

Cada proyecto/blog debe ser una CARD:

- fondo ligeramente distinto
- borde sutil
- hover suave
- separación clara

NO usar:
- listas con líneas infinitas
- bloques indistinguibles

---

### Tipografía

- títulos grandes
- texto secundario en gris
- evitar texto plano sin jerarquía

---

# 🧭 UX (OBLIGATORIO)
